# Phishing Email Investigation and Incident Response

## Objective
Analyze a phishing email and identify indicators of compromise.

## Tools Used
- Email analysis
- Incident response methodology

## Indicators of Compromise
- Spoofed sender domain
- Malicious link
- Social engineering tactics

## Skills Demonstrated
- Threat analysis
- Incident investigation
- Incident documentation

## Summary
This project demonstrates the ability to identify phishing attacks, analyze malicious indicators, and document incident response findings. These skills are essential for SOC Analyst roles.
